# AI JobMatch – Intelligent Job Recommendation System

AI JobMatch is a full-stack web application designed to recommend relevant job opportunities to candidates based on their resumes using Natural Language Processing (NLP), TF-IDF, Cosine Similarity, and weighted multi-criteria ranking algorithms.

## Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, React Router DOM, Axios, Context API
- **Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, Multer
- **AI/Recommendation Engine:** Natural.js, TF-IDF, Cosine Similarity, Content-Based Filtering, Weighted Scoring Model
- **Parsing:** Mammoth (DOCX), PDF-Parse (PDF)
